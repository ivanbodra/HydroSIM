# Principal-plane array tilt sensitivity

Status: controlled diagnostic derived from the HydroSIM principal-plane array-tilt reference experiment.

## Purpose

The array-tilt symmetry-break experiment establishes that a non-zero principal-plane array tilt can prevent the narrow sound-speed-at-transducer cancellation from closing. This document defines a repeatable sensitivity sweep that quantifies how the profile-frame Snell ray-parameter mismatch changes with tilt while holding the configured beam angle, transducer-sensor bias, platform attitude, finite-thickness profile, and bottom geometry fixed.

The sweep is a diagnostic layer. It does not add a new propagation law.

## Controlled variables

For one sweep, the following quantities are fixed:

- configured principal-plane beam angle `theta_cfg`;
- true local sound speed `c_true`;
- sound speed used by the sonar `c_used`;
- transducer-sensor bias `c_used - c_true`;
- true and processing finite-thickness profiles, which are identical for the transducer-only sensitivity curve;
- platform pose and flat-bottom geometry.

Only the principal-plane array tilt `tau` varies.

## Closed-form ray-parameter mismatch

The physical TX angle in array coordinates is

```text
theta_phys = asin((c_true / c_used) * sin(theta_cfg))
```

For the transducer-only case, the Truth and processing profile-frame ray parameters are

```text
p_truth(tau) = sin(tau + theta_phys) / c_true

p_processing(tau) = sin(tau + theta_cfg) / c_used
```

Define the signed diagnostic mismatch as

```text
Delta_p(tau) = p_processing(tau) - p_truth(tau)
```

Expanding the two sine terms gives

```text
Delta_p(tau) = sin(tau) * K
```

where

```text
K = cos(theta_cfg) / c_used - cos(theta_phys) / c_true
```

The cosine-weighted term proportional to `cos(tau)` cancels exactly because the steering relation requires

```text
sin(theta_cfg) / c_used = sin(theta_phys) / c_true
```

Therefore, within this reduced reciprocal principal-plane model:

- `Delta_p(0) = 0`;
- the ray-parameter mismatch is an odd function of tilt;
- equal positive and negative tilts produce equal-magnitude, opposite-sign ray-parameter mismatch;
- the small-tilt slope is exactly `K` at `tau = 0`.

This closed-form curve is an independent analytical anchor for the numerical sweep. It is not derived from the layered ray tracer.

## Sounding-error response

The study also records the calculated-minus-Truth sounding-error vector and its norm at each tilt. No symmetry law is imposed on the sounding-error norm. Even when the initial ray-parameter mismatch is analytically odd in tilt, the complete sounding response includes refraction, travel-time inversion, bottom intersection, and coordinate geometry. Those operations can produce a nonlinear relationship between `Delta_p` and final sounding error.

The ray-parameter curve is therefore the primary analytical diagnostic; the sounding-error curve is the numerical experiment response.

## Implementation

`run_principal_plane_array_tilt_sensitivity_study` samples the existing A/B/C/D experiment at each requested tilt and extracts the transducer-only case. The finite-thickness processing profile is kept equal to Truth so profile error is not introduced into this sweep.

Each point records:

- array tilt;
- signed Truth ray parameter;
- signed processing ray parameter;
- their signed mismatch;
- sounding-error vector;
- sounding-error norm.

The scalar ray parameters use the signed angle convention of the controlled principal-plane experiment. They are diagnostics and do not replace the vector tangential-slowness representation used by the general processing architecture.

## Validation

Two independent analytical checks are required:

1. direct closed-form evaluation of `p_truth`, `p_processing`, and `Delta_p` for negative, zero, and positive tilt;
2. centered finite-difference evaluation around zero tilt compared with the independent derivative `K`.

The zero-tilt point must preserve the earlier transducer-only closure. Non-zero tilt points must not be generalized into operational MBES accuracy claims.

## Scope and limitations

This sensitivity law applies only to the current controlled model assumptions: stationary reciprocal propagation, one principal plane, one common TX/RX array orientation, horizontal layered sound-speed structure, aligned platform pose, and flat-bottom geometry. It does not describe full 3-D Mills-cross installation geometry, independent TX/RX array rotations, vessel attitude dynamics, multi-sector timing, or sector association.

The analytical `Delta_p(tau)` law describes the ray-parameter mismatch generated by this reduced coordinate model. It is not a universal law for final sounding error in operational multibeam systems.
